# 남해 바래길 3일 도보여행 페이지

친구들과 공유할 여행 계획 페이지입니다. GitHub Pages로 무료로 올릴 수 있어요.

## GitHub Pages로 올리는 방법 (초간단, 깃 몰라도 됨)

1. github.com 접속 → 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name 입력 (예: `namhae-trip`) → Public 선택 → **Create repository**
3. 방금 만든 저장소 페이지에서 **Add file → Upload files** 클릭
4. 이 폴더 안의 `index.html` 파일과 `assets` 폴더(안의 이미지 5개)를 통째로 끌어다 놓기
   - `assets` 폴더째로 드래그하면 자동으로 하위 폴더 구조가 유지됩니다
5. 아래 **Commit changes** 클릭
6. 저장소 상단 메뉴 **Settings** → 왼쪽 메뉴 **Pages**
7. **Build and deployment → Branch**에서 `main` / `/ (root)` 선택 → **Save**
8. 1~2분 기다린 후 같은 페이지 상단에 뜨는 주소로 접속
   (형식: `https://아이디.github.io/namhae-trip/`)
9. 이 주소를 친구들에게 카톡으로 공유하면 끝!

이후 내용을 수정하고 싶으면 저장소에서 `index.html`을 열어 연필 아이콘(Edit)으로 바로 고칠 수 있어요.
